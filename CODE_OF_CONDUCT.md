# Code of Conduct

This project expects respectful, professional collaboration.

## Expected Behavior

- Be direct and constructive.
- Critique code and designs, not people.
- Assume public issues and pull requests are read by users with different backgrounds and experience levels.
- Avoid posting secrets, private logs, private repository content, or exploit details.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Doxing or publishing private information.
- Repeated off-topic disruption.
- Sharing credentials, private keys, or sensitive payloads in public project spaces.

## Enforcement

Maintainers may edit, hide, or remove comments and may block participants who repeatedly violate these expectations.
